# Stock Portfolio 📈

A web application built with Flask that lets users manage a virtual stock portfolio. Users can check stock prices, buy and sell shares, and keep track of their transactions.

## About the Project

I built this project as part of **CS50's Introduction to Computer Science** by Harvard University.

The idea is to simulate a simple stock trading platform. Each user has a virtual cash balance and can use it to buy and sell stocks. Stock prices are retrieved through an external API.

The application also keeps track of the user's portfolio and transaction history.

## Features

* User registration and login
* Checking stock prices
* Buying stocks
* Selling stocks
* Viewing the current portfolio
* Tracking available cash and portfolio value
* Viewing transaction history
* Password hashing and session management
* Input validation and error handling

## How It Works

Users first create an account and log in. After logging in, they can look up a stock by its symbol and check its current price.

They can then use their virtual cash to buy shares or sell shares they already own. The application checks the user's balance and holdings before completing a transaction.

The portfolio page shows the stocks the user owns, their current values, available cash, and the total portfolio value.

Every purchase and sale is also saved so the user can review their transaction history later.
